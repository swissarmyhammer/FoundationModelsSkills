Add this test. Do not change `ArgumentSubstitution.swift`.

Lines 110-111 are the `else` branch of the `.specialVariable(let name)`
case in the substitution loop. The branch runs when a `${VAR}` token
matches the grammar but `Self.specialVariables[name]` gives no value, or
its `resolve(request)` gives `nil`. The text then passes through
unchanged, and is *not* quarantined.

Write the test like this:

1. Render a skill body that holds a `${VAR}` token whose name is not in
   `specialVariables`, for example `${NOT_A_REAL_VARIABLE}`.
2. Make sure the rendered output holds the token text verbatim.
3. Make sure the output does not hold quarantine markers around that
   token. This is the point of the branch: an unresolved token is
   original text, not untrusted input.
4. Add a second case, if any entry in `specialVariables` can give `nil`
   from `resolve(request)`. Build a request that makes it give `nil`.
   Make sure that token also passes through verbatim.

Lines 251-252 -- the `preconditionFailure` at the end of the token
classifier -- cannot run: the grammar has no alternative outside the
five the classifier tests. Leave those lines uncovered.

Put the test in `Tests/FoundationModelsSkillsTests/`, next to the
argument-substitution tests that are there. #coverage-gap
