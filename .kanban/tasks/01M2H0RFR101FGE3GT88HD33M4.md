## What

marketplace.md §5.1 (the libgit2 decision) and decision 10. The package must not start the `git` binary.

- `Package.swift`: add `.package(url: "https://github.com/danielctull-forks/swift-libgit2.git", exact: "1.9.7")`, and add `.product(name: "libgit2", package: "swift-libgit2")` to `commonDependencies`. Comment the pin in the style of the `Yams` pin comment.
- `Sources/FoundationModelsSkills/Marketplace/Git/GitTransport.swift` — internal `protocol GitTransport: Sendable` with `func remoteHead(url: String, ref: String) async throws -> String` (40-hex SHA) and `func fetch(url: String, revision: String, intoBareRepository: URL) async throws -> String` (the fetched commit SHA). `GitTransportError` (unreachable, refNotFound, cancelled, timedOut, libgit2(code, message)).
- `Sources/FoundationModelsSkills/Marketplace/Git/LibGit2Transport.swift` — call `git_libgit2_init` one time. `remoteHead`: `git_remote_create_detached` → `git_remote_connect` (fetch direction) → `git_remote_ls`; match `refs/heads/<ref>`, `refs/tags/<ref>`, or `HEAD`. `fetch`: `git_repository_init` (bare) if missing → `git_remote_create_anonymous` → `git_remote_fetch` with `git_fetch_options.depth = 1` → resolve the commit. The `transfer_progress` and `sideband_progress` callbacks return non-zero when `Task.isCancelled`, and the call throws `.cancelled`. No built-in timeout.
- `Tests/FoundationModelsSkillsTests/GitFixtureRepository.swift` — a test helper that makes a repository **with libgit2** (no `git` binary): init, write blobs and trees (file, executable file, symlink), commit, move a branch, add a tag; gives a `file://` URL.
