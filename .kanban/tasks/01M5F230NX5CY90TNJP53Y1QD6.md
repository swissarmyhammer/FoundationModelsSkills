The endpoint lists **all** skills of the catalog, including ones with `enabled: false` (EXTRAS-9 table); the model-visible filter stays in the tool.
- No mutations and no Mutation type (D84; rules 7 and 10 do not apply).
- Alias tables (D86): `skill(name:)` → `skill(id:)`, plus `listSkills`/`getSkill`.
- Errors (rule 8 rev 2): no package `CodedError` unless a skills-specific code turns up; toolkit codes only.
