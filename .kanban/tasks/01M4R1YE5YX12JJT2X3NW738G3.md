## What
Extras commit `f7095e5` ("feat(marketplace)!: remove catalogVersion and catalog displayID from provenance") removed `catalogVersion` from `MarketplaceProvenance`. The display text of a marketplace is now `id@<short commit>`. When FoundationModelsSkills resolves Extras `main` at or after `f7095e5` (now `6ac66c1`), `swift build` passes but `swift test` does not compile:

```
Tests/FoundationModelsSkillsTests/MarketplaceTestSupport.swift:64:33: error: extra argument 'catalogVersion' in call
```

Files that use the removed value:
- `Tests/FoundationModelsSkillsTests/MarketplaceTestSupport.swift`: `makeMarketplaceLayer(root:id:sha:catalogVersion:)` and `defaultCatalogVersion`.
- `Tests/FoundationModelsSkillsTests/MarketplaceProvenanceDisplayTests.swift`: the `catalogVersion` fixture value, the `id@<version>` expectation, and the "falls back to the short commit when the catalog has no version" test.

## Work
1. Remove the `catalogVersion` parameter and `defaultCatalogVersion` from `MarketplaceTestSupport`, and update each caller.
2. Change `MarketplaceProvenanceDisplayTests` to the new contract: the source text of a marketplace row is `id@<short commit>`. Delete the version-only cases that the contract no longer has.
3. Search the docs (`README.md`, `docs/`) for text that says the source shows the catalog version, and correct it.

## Acceptance Criteria
- [ ] `swift build` and `swift test` pass in FoundationModelsSkills with Extras at `6ac66c1` or later.
- [ ] No test or doc names `catalogVersion`.
