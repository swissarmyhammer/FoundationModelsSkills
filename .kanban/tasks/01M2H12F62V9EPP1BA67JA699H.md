## What

marketplace.md §6.7 and §10 item 2. A managed host must be able to limit which marketplaces load. The check runs before any network or disk access.

- `Sources/FoundationModelsSkills/Marketplace/SourcePattern.swift`: `public enum SourcePattern: Sendable, Hashable, Codable` with `.exact(String)` (a normalized URL), `.owner(host: String, owner: String)` (for example `github.com` and `swissarmyhammer`; matches every repository of that owner over SSH or HTTPS, and the `github:` shorthand), `.hostRegex(String)`, and `.pathPrefix(String)` (for `file://` sources). Match on `MarketplaceLocation.normalizedURL`.
- `MarketplacePolicy`: `allowedSources: [SourcePattern]?` (default `nil` = allow all) and `blockedSources: [SourcePattern]` (default empty). An empty `allowedSources` array blocks every source. The blocklist wins over the allowlist.
- `MarketplaceStore`: evaluate the policy for each source in `init`. A refused source gets a diagnostic, gets no layer, and is never passed to `GitTransport`, `MarketplaceCache`, or the file system. This applies to `start()`, `check()`, `update()`, and the seed folder.

- [ ] `SourcePattern` and its matching
- [ ] The policy fields and the allow/block rule
- [ ] Enforcement in `MarketplaceStore` before any I/O
