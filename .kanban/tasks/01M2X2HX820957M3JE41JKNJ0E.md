## What

The catalog entry of `SkillsRegistry` (`Sources/FoundationModelsSkills/Registry/SkillsRegistry.swift`) holds one `skillDirectory` and one `winningLayer`. With the combined view a skill has more than one layer directory, and a file can come from a layer that is not the layer of `SKILL.md`.

There is no marketplace grant. The user removed that concept on 2026-09-19. A marketplace layer is an untrusted layer like `user` and `project`, and the host `RenderPolicy` is the only policy.

1. The entry holds `contributingDirectories` (the value that `DiscoveredSkill` now gives), lowest precedence first.
2. The entry holds the layer of **each** contributing directory, not of the winning `SKILL.md` only. The later resource cards use this to say which layer gives a file.
3. `winningLayer` stays. It is the layer of `SKILL.md`, and the render keeps it for the trust of the render and for the scope of the partials.
4. The validator (`Sources/FoundationModelsSkills/Validation/SkillValidator.swift`) reads the winning `SKILL.md` as it does now. No change of rule.
