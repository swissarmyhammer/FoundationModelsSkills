# Base Style

This is the **defaults**-layer copy of the `base-style` skill: the lowest
layer of the three-layer `.skills` dotfolder stack (plan.md §11).

It is shadowed by the `user` layer's copy of the same id at
`user/base-style/SKILL.md` -- the full-replace override wins entirely
(decision #3), so a discovery pass over the whole stack only ever surfaces
the user-layer text below, never this one.
